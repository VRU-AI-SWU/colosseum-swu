## 5. เข้าสู่ระบบและรับโทเคน

ตรวจว่าตั้งติดจริง — อันแรกต้องพิมพ์ URL กลับมา อันที่สองต้องได้ตัวเลขราวๆ 32

### รหัสเชิญ กับ โทเคน — คนละอย่างกัน

ในแถบทีมมีสองรหัส หน้าตาคล้ายกันแต่ทำคนละหน้าที่ **สลับกันไม่ได้**

| | 🎟️ รหัสเชิญ · 6 ตัว | 🔑 โทเคน · 32 ตัว |
|---|---|---|
| ตอบคำถาม | "ฉันจะเข้าทีมนี้ได้ยังไง" | "ฉันคือทีมนี้จริง" |
| ใช้ที่ไหน | ปุ่ม **เข้าทีมเพื่อน** บนหน้าเว็บ | `ARENA_TOKEN` บนเครื่องตัวเอง |
| บอกใครได้ | เพื่อนในกลุ่ม · อ่านให้ฟังในห้องได้ | **ห้ามบอกใคร — เป็นรหัสผ่าน** |
| ถ้าหลุด | คนอื่นเข้ามาในทีมได้ (เห็นชื่อได้ว่าใครเพิ่ม) | คนอื่น**ส่งงานในนามคุณ**ได้ · กินโควตา · เห็นคะแนนรายตอนของคุณ |

⚠️ **อย่า commit โทเคนขึ้น GitHub** — เป็นวิธีที่รหัสผ่านหลุดบ่อยที่สุด ใช้ตัวแปร
แวดล้อมอย่างข้างบน อย่าเขียนลงไฟล์ในโฟลเดอร์ที่จะถูกส่งขึ้นระบบ

**ถ้าโทเคนหลุดไปแล้ว** กดปุ่ม **โทเคนหลุด?** ในแถบทีมบนหน้าเว็บ ระบบจะออกตัวใหม่ให้
และตัวเก่าใช้ไม่ได้ทันที · ถ้าอยู่เป็นทีม อย่าลืมส่งตัวใหม่ให้เพื่อนด้วย เพราะทุกคน
ในทีมใช้โทเคนเดียวกัน

### จับทีม

**ทำคนเดียวก็ได้** — ล็อกอินแล้วคุณมีทีมของตัวเองอยู่แล้ว ส่งงานได้เลย ไม่ต้องทำอะไรเพิ่ม

ถ้าจะรวมทีม (ไม่เกิน 6 คน)

1. คนหนึ่งเป็นเจ้าของทีม → คัดลอก **รหัสเชิญ** จากแถบทีมส่งให้เพื่อน
2. เพื่อนล็อกอินของตัวเอง → กด **เข้าทีมเพื่อน** → ใส่รหัส
3. ทีมเดี่ยวเดิมของเพื่อนถูกยุบ และ**คะแนนเดิมของเขาหายจาก leaderboard**
   เพราะเป็นผลงานของคนเดียว ไม่ใช่ของทีมใหม่ — รวมทีมให้เรียบร้อยก่อนเริ่มส่งงานจริง

หลังรวมทีมแล้ว **ทั้งทีมใช้โทเคนตัวเดียวกัน** งานที่ใครส่งก็เป็นของทีม

## โจทย์เปลี่ยนสามครั้งตลอดเทอม

**นี่คือเรื่องที่ทำให้คนตกใจมากที่สุดถ้าไม่รู้ล่วงหน้า** — การแข่งแบ่งเป็นสามช่วง
และแต่ละช่วง**เปลี่ยนตัวโจทย์เอง** ไม่ใช่แค่เปลี่ยนวันส่ง

| ช่วง | ห้อง | เห็นอะไร | ความยุ่งเหยิง | เวลา |
|---|---|---|---|---|
| **Warm-up** | 10×10 | ทั้งห้อง | ไม่มีเลย | 250 step |
| **Main** | 20×20 | รอบตัว 5×5 | เดินพลาด · เซนเซอร์ผิด · ช่องเหนียว | 1,500 step |
| **Final** | 30×30 | รอบตัว 3×3 | เหมือน Main + ฝุ่นกระจุกตัว | 3,000 step |

วันที่ของแต่ละช่วงดูได้ที่ <https://colosseum.vru-ai.com> ด้านบนของหน้า
ช่วงที่กำลังแข่งอยู่จะถูกไฮไลต์ไว้ พร้อมบอกว่าเหลือกี่วัน

**สิ่งที่ตามมาจากตารางนี้**

- **agent ที่เชื่อเซนเซอร์ตรงๆ จะพังทันทีที่เข้า Main** — Warm-up ไม่มี noise เลย
  โค้ดที่สมมติว่า "เห็นอะไรคือจริง" จึงทำงานได้ดีในช่วงนั้นแล้วคะแนนตกฮวบวันที่เปลี่ยนช่วง
  ถ้าไม่รู้ที่มา จะไล่ debug อัลกอริทึมผิดทางเป็นวัน
- **agent ที่จำแผนที่ไม่ได้จะตันที่ Main** — พอเห็นแค่ 5×5 การเดินสุ่มไม่พาไปทั่วห้อง
  20×20 ได้ใน 1,500 step
- **Final ต่างจาก Main ที่ "ต้องวางแผนไกลแค่ไหน"** — ห้องใหญ่ขึ้น 2.25 เท่า
  มองเห็นแคบลง และฝุ่นกระจุกเป็นหย่อม การเดินไล่ทีละช่องที่เห็นจะไม่ทัน

ทดสอบช่วงไหนก็ได้ในเครื่องตัวเองตั้งแต่วันนี้ ไม่ต้องรอถึงวันจริง

```bash
arena eval --config warmup --seeds 1-20
arena eval --config final --seeds 1-20
```

## คะแนนคิดยังไง

```
คะแนนต่อ episode = พื้นที่ใต้กราฟ coverage เทียบกับเวลา   (สูงสุด 1.0)
                 + 1.0 ถ้าดูดครบ 100%
                 − penalty จากการชนกำแพงและดูดช่องที่สะอาดแล้ว   (สูงสุด 0.2)
```

สองอย่างที่ตามมาจากสูตรนี้ และมันสำคัญมาก

1. **ดูดครบสำคัญกว่าดูดเร็ว** — โบนัส 1.0 ก้อนเดียวใหญ่กว่าความต่างของความเร็วเกือบทุกกรณี
   ทีมที่ดูดครบจะอยู่เหนือทีมที่ดูดไม่ครบเสมอ
2. **ในกลุ่มที่ดูดครบด้วยกัน แข่งกันที่จำนวนก้าว** — จบเร็วกว่า = AUC สูงกว่า

**ไม่มีการนับเวลาจริง (wall-clock) เข้าคะแนนเลย** — agent ที่คิดนานแต่เดินน้อย
ได้เปรียบ agent ที่คิดเร็วแต่เดินมั่ว เครื่องแรงไม่ได้เปรียบ

| Windows: ส่งงานแล้วขึ้น 401 | `$env:ARENA_TOKEN` หายเมื่อปิดหน้าต่าง · ใช้ `setx` แล้วเปิดหน้าต่างใหม่ |
| Windows: prompt กลายเป็น `>>` | คำสั่งยังไม่จบในสายตา PowerShell — กด **Ctrl + C** แล้วพิมพ์ใหม่ด้วย `'` เดี่ยว |
| `arena eval` ขึ้น `ไม่พบ agent.py` | ยืนผิดโฟลเดอร์ — `cd my-agent` ก่อน (หรือใช้ `--dir my-agent`) |

### ดูว่า agent เดินยังไง

```bash
arena eval --config main --seeds 1-3 --replay-dir ./replays
python -m vacuum.viewer replays/1.vrp
```

คำสั่งที่สองสร้าง `replays/1.html` แล้วเปิดในเบราว์เซอร์ให้เลย — เดินทีละ step
ถอยหลังได้ ลากไทม์ไลน์ได้ และมีปุ่มสองอันที่ตอบคำถาม "ทำไมคะแนนต่ำ" ได้เร็วที่สุด

| ปุ่ม | ใช้ตอนไหน |
|---|---|
| **แผนที่ความหนาแน่น** | สีเข้ม = อยู่ตรงนั้นนาน · agent ที่วนอยู่มุมเดียวจะเห็นทันที |
| **จุดที่ติด ▸** | กระโดดไปช่วงที่ชน/ดูดซ้ำ/ดูดไม่ขึ้นถี่ที่สุด |

แถบใต้ห้องคือไทม์ไลน์ทั้ง episode — ขีดเขียวคือดูดสำเร็จ ขีดแดงคือปัญหา

ไฟล์ HTML ที่ได้ทำงานได้เองทั้งหมด ไม่ต้องต่อเน็ต แนบในรายงานหรือส่งให้เพื่อนดูได้

## กฎที่มักทำให้เสียคะแนนโดยไม่รู้ตัว

- **`reset()` ต้องล้าง state ให้หมด** — ระบบตรวจด้วยการรัน episode เดียวกันทั้งแบบต่อกัน
  และแบบแยกกระบวนการ ถ้าคะแนนไม่ตรง submission ถูกปฏิเสธ
  **ตรวจเองก่อนส่งด้วย `arena eval --check-reset`** — ถ้าไม่ตรวจ อาการที่คุณเห็นจะเป็นแค่
  "คะแนนต่ำกว่าที่ควร" แล้วไล่ debug อัลกอริทึมผิดทางเป็นชั่วโมง
- **ไม่มีอินเทอร์เน็ตตอนรัน** — โหลด weights เพิ่มไม่ได้ ต้องแพ็กมาให้ครบ
- **ใช้ได้เฉพาะ package ที่อนุญาต** — stdlib + `numpy` + `torch` + `vacuum`
- **ห้ามใช้ `np.random.seed()`** ในโค้ดของคุณ ให้สร้าง `np.random.Generator` ของตัวเองแทน
  (ไม่ได้ทำให้ผังห้องเปลี่ยน แต่ทำให้ผลของ*คุณเอง*ทำซ้ำไม่ได้ ซึ่งทำให้ debug ยากมาก)
- **agent ต้องคืน `int` ในช่วง 0–5** ทุกครั้ง คืนอย่างอื่น = episode นั้นได้ 0
  (`np.int64` ที่ได้จาก `np.argmax` ใช้ได้ ไม่ต้อง cast — แต่ `float` ไม่ได้)
- **seed ที่ใช้ตัดสินไม่ใช่ seed ที่คุณเทรน** — ห้องใหม่ทั้งหมด จำผังห้องไม่ได้

## อ่านต่อ

เปิดดูได้จากในแพ็กเกจที่ติดตั้งแล้ว — หา path ด้วย
`python -c "import vacuum, pathlib; print(pathlib.Path(vacuum.__file__).parent)"`

- **`vacuum/baselines/`** — โค้ดของ 🥉 Bronze กับ 🥈 Silver อ่านได้เต็ม
  · `common.py` มี `WorldModel` — แผนที่ที่สะสมสิ่งที่เคยเห็น พร้อมใช้ ไม่ต้องเขียนเอง
  · `decode_pos` — แปลง `obs["pos"]` เป็นพิกัดจำนวนเต็มอย่างถูกต้อง
  · 🔒 โค้ดของ Gold/Diamond ไม่อยู่ในแพ็กเกจ ตั้งใจไว้อย่างนั้น
- **`vacuum/examples/train_ppo.py`** — ถ้าจะเทรน policy เอง (`pip install "cp463-vacuum[train]"`)
- **`vacuum/examples/reward_wrappers.py`** — ⚠️ **reward ที่ใช้ตอนเทรน ≠ metric ที่ใช้ตัดสิน**
  การออกแบบ reward เป็นส่วนหนึ่งของคำตอบ ไม่ใช่ส่วนหนึ่งของโจทย์
- **`vacuum.rollout.evaluate`** — เรียกจากสคริปต์ Python ได้ถ้าอยากได้ตัวเลขดิบ
  ⚠️ มันสร้าง agent **ใหม่ทุก episode** จึง**มองไม่เห็นบั๊ก `reset()`** — ใช้ `arena eval` แทน
  เมื่อต้องการผลที่ตรงกับตอนตัดสิน
- **spec เต็มของโจทย์** — ผู้สอนแจกลิงก์ให้ในคาบเรียน
