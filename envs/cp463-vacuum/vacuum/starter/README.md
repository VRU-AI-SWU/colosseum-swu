# CP463 · Vacuum Robot Challenge — เริ่มตรงนี้

หุ่นดูดฝุ่นอยู่ในห้องที่สุ่มขึ้นมาใหม่ทุกครั้ง เป้าหมายคือ **ดูดให้ครบทุกช่อง โดยใช้จำนวนก้าวน้อยที่สุด**

คุณเขียนแค่ `agent.py` ไฟล์เดียว ส่งขึ้นระบบ แล้วเห็นคะแนนของตัวเองเทียบกับทีมอื่นบน leaderboard
ส่งได้วันละ 5 ครั้งตลอดเทอม

---

## 1. ติดตั้ง (ครั้งเดียว)

```bash
python3.11 -m venv .venv && source .venv/bin/activate
pip install cp463-vacuum colosseum
```

ต้องใช้ **Python 3.11** — เวอร์ชันอื่นจะได้ผังห้องคนละแบบกับที่ใช้ตัดสิน

- `cp463-vacuum` คือ environment ของโจทย์
- `colosseum` คือคำสั่ง `arena` ที่ใช้ส่งงานและวัดผลในเครื่อง

## 2. ตรวจว่าเครื่องคุณพร้อม

```bash
python -m vacuum.selfcheck
```

คำสั่งนี้ยืนยันว่า environment ในเครื่องคุณ **ให้ผลตรงกับตัวที่ใช้ตัดสินคะแนนทุกบิต**
ถ้าผ่าน คะแนนที่คุณวัดเองจะเทียบกับ leaderboard ได้ตรงๆ ถ้าไม่ผ่าน**อย่าเพิ่งเริ่มเขียน** —
แก้ให้ผ่านก่อน ไม่งั้นคุณจะจูนบนสิ่งที่ไม่ตรงกับตอนวัดจริง

## 3. รัน agent ตัวอย่าง

```bash
arena eval --config main --seeds 1-20
```

จะได้ประมาณนี้

```
seed ที่ใช้     20 ตัว (1-20)
คะแนนรวม       +0.2xxx
ดูดครบ         0/20
coverage เฉลี่ย 0.5xx
```

ยินดีด้วย คุณอยู่ระดับ 🥉 Bronze แล้ว 🎉 ทีนี้มาทำให้ดีกว่านี้กัน

## 4. แก้ `agent.py`

สามเมธอด — `__init__` · `reset` · `act` รายละเอียดอยู่ในคอมเมนต์ของไฟล์

เปิดดูตัวอย่างที่รันได้จริงของแต่ละระดับได้ที่

```python
from vacuum.baselines import RandomAgent, GreedyAgent, BFSCoverageAgent, BeliefBFSAgent
```

## 5. ส่ง

```bash
arena submit cp463-vacuum-1-2026 --note "จำแผนที่แล้วเดินหาฝุ่นที่ใกล้ที่สุด"
arena leaderboard cp463-vacuum-1-2026
```

`--dry-run` ทดสอบว่าแพ็กไฟล์ถูกโดย **ไม่กินโควตา** — ใช้ก่อนส่งจริงครั้งแรกเสมอ

## คุณอยู่ตรงไหน

หมุดบน leaderboard (ค่าอ้างอิงจาก config `main`)

| | คะแนน | ต่างจากระดับก่อนหน้าตรงไหน |
|---|---|---|
| 🥉 Bronze | ~0.24 | เดินสุ่ม ดูดเมื่อเจอฝุ่นใต้ตัว |
| 🥈 Silver | ~0.81 | เดินเข้าหาฝุ่นที่**เห็นอยู่ในหน้าต่าง** |
| 🥇 Gold | ~1.72 | **จำแผนที่** แล้ววางแผนไปหาฝุ่นที่เคยเห็นและพื้นที่ที่ยังไม่เคยไป |
| 💎 Diamond | ~1.80 | **ไม่เชื่อเซนเซอร์ตรงๆ** — รวมหลักฐานจากการเห็นซ้ำก่อนตัดสินใจ |
| เพดานของสูตร | 2.00 | |

ช่องว่างที่กว้างที่สุดคือ Silver → Gold ซึ่งคือการเปลี่ยนจาก "ตอบสนองสิ่งที่เห็น"
ไปเป็น "สร้างแบบจำลองของโลกแล้ววางแผนบนมัน"

> **ไม่มีการบังคับว่าต้องใช้อัลกอริทึมตระกูลไหน** — จะเขียน planner มือ เทรน RL หรือผสมกันก็ได้
> leaderboard วัดคุณภาพของ agent อย่างเดียว ส่วนความเข้าใจว่า*ทำไม*วิธีของคุณถึงเหมาะกับโจทย์นี้
> ถูกวัดที่รายงาน ซึ่งบังคับให้ส่งทั้ง planner และ learned policy แล้ววิเคราะห์เปรียบเทียบ

## คะแนนคิดยังไง

```
คะแนนต่อ episode = พื้นที่ใต้กราฟ coverage เทียบกับเวลา   (สูงสุด 1.0)
                 + 1.0 ถ้าดูดครบ 100%
                 − penalty จากการชนกำแพงและดูดช่องที่สะอาดแล้ว   (สูงสุด 0.2)
```

สองอย่างที่ตามมาจากสูตรนี้ และมันสำคัญมาก

1. **ดูดครบสำคัญกว่าดูดเร็ว** — โบนัส 1.0 ก้อนเดียวใหญ่กว่าความต่างของความเร็วเกือบทุกกรณี
   ทีมที่ดูดครบจะอยู่เหนือทีมที่ดูดไม่ครบเสมอ
2. **ในกลุ่มที่ดูดครบด้วยกัน แข่งกันที่จำนวนก้าว** — จบเร็วกว่า = AUC สูงกว่า

**ไม่มีการนับเวลาจริง (wall-clock) เข้าคะแนนเลย** — agent ที่คิดนานแต่เดินน้อย
ได้เปรียบ agent ที่คิดเร็วแต่เดินมั่ว เครื่องแรงไม่ได้เปรียบ

## เมื่อติดปัญหา

| อยากรู้ | ดูที่ |
|---|---|
| agent พังตรงไหน | `arena status <submission-id>` — traceback ของคุณอยู่ตรงนั้น |

## กฎที่มักทำให้เสียคะแนนโดยไม่รู้ตัว

- **`reset()` ต้องล้าง state ให้หมด** — ระบบตรวจด้วยการรัน episode เดียวกันทั้งแบบต่อกัน
  และแบบแยกกระบวนการ ถ้าคะแนนไม่ตรง submission ถูกปฏิเสธ
- **ไม่มีอินเทอร์เน็ตตอนรัน** — โหลด weights เพิ่มไม่ได้ ต้องแพ็กมาให้ครบ
- **ใช้ได้เฉพาะ package ที่อนุญาต** — stdlib + `numpy` + `torch` + `vacuum`
- **ห้ามใช้ `np.random.seed()`** ในโค้ดของคุณ ให้สร้าง `np.random.Generator` ของตัวเองแทน
  (ไม่ได้ทำให้ผังห้องเปลี่ยน แต่ทำให้ผลของ*คุณเอง*ทำซ้ำไม่ได้ ซึ่งทำให้ debug ยากมาก)
- **agent ต้องคืน `int` ในช่วง 0–5** ทุกครั้ง คืนอย่างอื่น = episode นั้นได้ 0
- **seed ที่ใช้ตัดสินไม่ใช่ seed ที่คุณเทรน** — ห้องใหม่ทั้งหมด จำผังห้องไม่ได้
