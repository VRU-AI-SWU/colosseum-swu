# หน้าเว็บ leaderboard

ไฟล์เดียว ไม่มีขั้นตอน build ไม่มี framework — `index.html` เปิดตรงๆ ก็ทำงาน

## ทำไมไม่มี build step

หน้านี้มีหน้าที่เดียวคือแสดง JSON จาก API ให้อ่านง่าย การใส่ bundler เข้ามาแปลว่า
ทุกคนที่จะแก้สีหรือเพิ่มคอลัมน์ต้องลง toolchain ก่อน ซึ่งไม่คุ้มกับสิ่งที่ได้
ปลายทางของ API เดาจาก `location.hostname` เอาเอง จึงไม่ต้องมีไฟล์ config ต่อ environment

    localhost / 127.0.0.1   →  http://localhost:8000
    ที่อื่น                  →  https://colosseum-api.vru-ai.com

## รันตอนพัฒนา

ต้องรันสองอย่าง — API กับตัวเสิร์ฟไฟล์ static · **`--allow-origin` ต้องตรงกับ origin
ของหน้าเว็บเป๊ะๆ** ไม่งั้นเบราว์เซอร์บล็อกทุก request

```bash
ARENA_SECRETS=/path/to/colosseum-hypogeum python -m core.cli serve --port 8000 --real-seeds --allow-origin http://localhost:4321
```

```bash
python3 -m http.server 4321 --directory web --bind 127.0.0.1
```

แล้วเปิด <http://localhost:4321> ใส่โทเคน `team-1`

## deploy

เป็น **Worker ที่เสิร์ฟ static asset อย่างเดียว** ไม่ใช่ Pages — แบบเดียวกับ `vru-ai-web`
ที่เสิร์ฟเว็บแล็บอยู่แล้ว ตั้งค่าทั้งหมดอยู่ใน [`wrangler.jsonc`](../wrangler.jsonc) ที่ราก repo
รวมถึงการผูกโดเมน จึงเห็นจากในโค้ดได้ว่าอะไรชี้มาที่นี่

```bash
npx wrangler deploy
```

ขึ้น <https://colosseum.vru-ai.com> · ฝั่ง API อนุญาต origin นี้ไว้แล้วใน
[`deploy/systemd/arena-api.service`](../deploy/systemd/arena-api.service)
(`--allow-origin https://colosseum.vru-ai.com`)

ไฟล์ทุกไฟล์ใน `web/` ถูกเสิร์ฟสาธารณะ — ของที่ไม่ควรให้นิสิตเห็นต้องใส่ใน `.assetsignore`
(README นี้อยู่ในนั้นแล้ว)

## รูป hero

หน้านี้คาดหวังไฟล์ **`web/colosseum.jpg`** — ถ้าไม่มี แถบด้านบนจะเป็นสีพื้นเข้มพร้อมชื่อ
ซึ่งยังดูเรียบร้อย ไม่พังเป็นกล่องว่าง

| | |
|---|---|
| ขนาด | กว้าง ~1920 px · แนวนอน · ตัวอาคารอยู่กลางภาพ |
| น้ำหนัก | **ต่ำกว่า 300 KB** — นิสิตเปิดผ่าน wifi มหาลัย รูป 4K จากกล้องหนัก 3–5 MB |
| สิทธิ์ | ⚠️ ถ้าไม่ใช่รูปที่เราถ่ายเอง ต้องเป็นสัญญาอนุญาตที่ใช้บนเว็บสาธารณะได้ |

**ห้ามใช้ภาพสต็อกที่ยังไม่ได้ซื้อสิทธิ์** — เจ้าของภาพสต็อกไล่เก็บค่าลิขสิทธิ์ย้อนหลัง
จากเว็บสาธารณะเป็นเรื่องปกติ และนี่เป็นเว็บของมหาวิทยาลัย · ถ้ารูปที่ใช้บังคับให้ระบุ
ที่มา (CC BY, Unsplash) ให้ใส่ใน `PHOTO_CREDIT` ใน `index.html` แล้วมันจะโผล่มุมล่างขวาของรูป

ย่อรูปก่อนใส่

```bash
sips -Z 1920 -s formatOptions 80 ต้นฉบับ.jpg --out web/colosseum.jpg
```

**ตั้งใจไม่ทำรูปเป็น background ของทั้งหน้า** — หน้านี้คือตาราง ตัวเลขต้องอ่านง่ายที่สุด
รูปที่มีทั้งท้องฟ้าสว่างและเงาเข้มอยู่ใต้ตัวเลขจะทำให้บางแถวอ่านยากเสมอ ไม่ว่าจะใส่ฝ้า
หนาแค่ไหน · แยกเป็นแถบ hero จึงได้ทั้งรูปที่เห็นเต็มตาและตารางที่อ่านออก 100%

## สิ่งที่หน้านี้ทำและไม่ทำ

ทำ — leaderboard สาธารณะ · หมุด baseline แทรกตามคะแนน · เป้าหมายถัดไปของทีมคุณ
([README §6.2](../README.md) บอกว่าข้อนี้คือหัวใจ: ทุกทีมต้องมีเป้าที่ทำได้เสมอ) ·
สถานะคิว · รีเฟรชเองทุก 30 วินาที

**ไม่ทำ — การส่งงาน** ยังต้องใช้ `arena submit` จาก terminal โดยตั้งใจ เพราะการส่งงาน
ต้องแพ็กโฟลเดอร์ทั้งชุดพร้อมข้ามไฟล์ที่ไม่ควรส่ง (`models/`, `.venv/`) ซึ่ง CLI ทำให้แล้ว
การทำอัพโหลดผ่านเว็บจะกลายเป็นการสอนให้นิสิต zip เองแล้วเจอปัญหาไฟล์เกินขนาด

## รหัสเชิญ กับ โทเคน

หน้านี้แสดงสองรหัสในแถบทีม ซึ่งทำคนละหน้าที่และมีความอ่อนไหวต่างกันมาก

| | 🎟️ รหัสเชิญ · 6 ตัว | 🔑 โทเคน · 32 ตัว |
|---|---|---|
| ใช้ทำอะไร | ให้เพื่อนกด "เข้าทีมเพื่อน" | `ARENA_TOKEN` ของ `arena submit` |
| บอกใครได้ | เพื่อนในกลุ่ม · อ่านให้ฟังได้ | **ห้ามบอกใคร — เป็นรหัสผ่าน** |
| ยาวเท่านี้เพราะ | ต้องอ่านให้เพื่อนฟัง จึงตัด `0/O/1/I/L` ออก | ไม่มีใครต้องพิมพ์เอง — copy อย่างเดียว |

**Google login ไม่ได้แทนที่โทเคน** — `arena submit` รันจาก terminal จึงต้องมี
credential ที่อยู่ได้นานเสมอ สิ่งที่การล็อกอินเปลี่ยนคือ*วิธีที่โทเคนถูกแจก*
จาก "ผู้สอนส่งให้ทีละคน" เป็น "นิสิตล็อกอินแล้วเห็นของตัวเอง"

โทเคนถูกส่งกลับมาทาง fragment ของ URL (`#token=…`) แล้วหน้าเว็บ**ล้างทิ้งทันที** —
fragment ไม่ถูกส่งไปเซิร์ฟเวอร์ จึงไม่ไปโผล่ใน access log และไม่ค้างในช่อง URL
ให้คนข้างๆ เห็นหรือติดไปกับลิงก์ที่นิสิตแชร์กัน

ช่องใส่โทเคนเองยังอยู่เป็นทางรอง — สำหรับ dev และกรณีผู้สอนแจกโทเคนตรงๆ

**โทเคนหลุดแล้วเปลี่ยนเองได้** — ปุ่ม "โทเคนหลุด?" ในแถบทีม → `POST /api/teams/rotate-token`
ยืนยันด้วยโทเคน*เดิม* ซึ่งฟังดูย้อนแย้งแต่ถูกต้อง: คนที่ยังถืออยู่คือเจ้าของโดยนิยาม
และถ้ามีคนอื่นถือด้วยก็ยิ่งต้องรีบเปลี่ยน · คนที่กดก่อนได้ก่อน ฝ่ายที่ถูกตัดออกต้อง
ไปคุยกับผู้สอน

หน้าเว็บเตือนก่อนกดว่ากระทบเพื่อนร่วมทีมกี่คน และใส่โทเคนใหม่ลง clipboard ให้เลย
— ผลย้อนกลับไม่ได้ ต้องบอกให้ครบก่อน ไม่ใช่หลังกด

⚠️ **รหัสเชิญยังเปลี่ยนไม่ได้** — ผลเสียต่ำกว่ามาก (คนแปลกหน้าเข้าทีมได้ ซึ่งเห็นชื่อ
และแก้ได้) แต่ถ้าเจอปัญหาจริงค่อยเพิ่มด้วยกลไกเดียวกัน
